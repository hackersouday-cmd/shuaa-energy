نظام شعاع الطاقة - نسخة تجريبية محلية

التشغيل على Windows:
1) افتح PowerShell داخل هذا المجلد.
2) python -m venv .venv
3) .\.venv\Scripts\Activate.ps1
4) pip install -r requirements.txt
5) python app.py
6) افتح Chrome على http://127.0.0.1:5000
